Lista de Comandos Git Aprendidos:
1. git init: Inicializa um repositório Git.
2. git clone: Clona um repositório remoto.
3. git add: Adiciona arquivos à área de staging.
4. git commit: Confirma as alterações no repositório local.
5. git status: Mostra o status dos arquivos. 
6. git branch: Lista branches ou cria uma nova uma nova branch
7. git checkout: Muda para outra branch
8. git git push origin <branch>: Envia branch para o repositório remoto

(Extras: Senha inválida (Tive que criar token clássico), Senha inválida (o GitHub exige Personal Access Token no terminal em vez de senha comum), Push rejeitado (o site tinha arquivos novos e você precisou dar pull antes de enviar), Conflito de mesclagem (o mesmo arquivo mudou nos dois lados e você teve que apagar as marcações <<<<<<< e ======= manualmente), Históricos sem relação (o Git achou que eram projetos diferentes e foi resolvido liberando o histórico ou forçando o push), Pasta errada (o comando falhou porque o terminal não estava dentro da pasta do projeto via cd), Nada para enviar (o Git avisou que tudo estava atualizado porque nenhum arquivo foi alterado e salvo antes do commit)
